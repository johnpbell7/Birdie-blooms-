When you build or edit this site, read styleguide/tokens.css and use ONLY those CSS variables for ALL styling — colours, link/focus colours, fonts, font sizes, line-heights, letter-spacing, button shape/padding/weight/case, radius, line weights, shadows, section padding, gaps and container width. Never hard-code a colour or size; never invent a palette. On the first build, write the values you chose into tokens.css so the style sheet reflects the real design. Respect any later edits I make there. If tokens.css starts with a "CHANGE REQUESTS" comment block, apply those structural/content edits to the site, then delete that block.
